# Privacy Policy

IG Hidden Mentions is designed to process data locally in the user's browser.

## Data collection

The extension does not intentionally collect, transmit, sell, or store personal data on an external server.

## Page access

When the user explicitly clicks the extension while an Instagram page is active, the extension temporarily reads content from that active tab in order to detect `ig_mention` data and associated usernames.

## Storage

The MVP does not persist scan results or maintain a browsing history.

## Network activity

The scanner may request the same Instagram page that is already open in the current authenticated browser session in order to inspect its returned HTML. This request is made directly by the browser to Instagram and is not proxied through a developer-controlled server.

## Third parties

This project is not affiliated with, sponsored by, or endorsed by Instagram or Meta.
